- **Grounded stack:** React, Redux Toolkit, Node.js, Express, MongoDB/Mongoose.
- **Grounded features:** common login for admin, organizer, exhibitor, attendee roles; dashboards; booth floor planning; analytics; session scheduling.
- **Limits:** source structure reviewed, but production deployment, role-based security, full integration tests and actual end-user metrics are not confirmed.
- **Portfolio presentation:** private source; no fake GitHub public link.

## LeadFlow AI (featured; public overview / local implementation)
- **Source reviewed:** `rufgdj.zip`, including `app.py`, `README.md`, source directories, `.env.example` and automated test files.
- **Grounded stack:** Python, Streamlit, Playwright, external business-search API, AI API, Excel workbook export.
- **Grounded workflow:** business search -> site audit/screenshot/outreach draft -> Excel export with resumable checkpoints.
- **Limits:** services require users' own API credentials; full GitHub implementation availability is not presumed; actual running screenshot not received.
- **Safety:** NEVER publish the supplied `.env`, raw lead exports, personal customer data or private API keys. Only a sanitized repository documentation draft is supplied separately.
